# Data

## Real BETH data (not in the repo)

Dataset: BETH, by Highnam, Arulkumaran, Hanif and Jennings (Kaggle: `katehighnam/beth-dataset`). It holds about 8 million
events from 23 cloud honeypots; this project uses the three process-log splits.

The Kaggle download contains these files; the pipeline reads the first three:

| File | Events | Hosts | Attacks (`evil`) |
|---|---|---|---|
| `labelled_training_data.csv` | 763,144 | 8 | none |
| `labelled_validation_data.csv` | 188,967 | 4 | none |
| `labelled_testing_data.csv` | 188,967 | 1 | 158,432 events (83.8%) |

The archive also holds raw per-host files (`labelled_2021may-ip-10-100-1-*.csv`, `labelled_2021may-ubuntu.csv`) and small
`*-dns.csv` files. They are not used. Put the three files above in `data/beth/` (git-ignored).

Download options:

- **In the browser:** download the archive from the Kaggle dataset page, unzip it, and copy the three files into `data/beth/`.
- **Kaggle CLI:** create a Kaggle API token (Account settings > API > Create New Token), save it as `~/.kaggle/kaggle.json`
  (never inside this repo), then run `bash scripts/download_beth.sh`.

Columns used: `timestamp, processId, parentProcessId, userId, processName, hostName, eventName, returnValue, args`
(plus `sus` and `evil` for benchmarking only). `args` is a Python-style list of dicts such as
`[{'name': 'pathname', 'type': 'const char*', 'value': '/etc/passwd'}]`.

Then run `python -m triage describe --data data/beth/labelled_testing_data.csv` and
`python -m triage benchmark --data-dir data/beth`.

## Synthetic sample (in the repo)

`data/sample/` is generated by `scripts/make_sample_data.py`. It is BETH-shaped and fake: it exists so tests, CI and a first
demo work before anyone downloads BETH. In it `sus` equals `evil`, which is not true of the real data, so baseline
comparisons on the sample mean nothing.
