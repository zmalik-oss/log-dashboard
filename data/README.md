# Data

## Real BETH data (not in the repo)

Dataset: BETH, by Highnam, Arulkumaran, Hanif and Jennings. Per the Kaggle description it holds about
8 million events from 23 cloud honeypots; the process-log subset is split into train, validation and test.
Published studies using it report that the train (8 hosts) and validation (4 hosts) splits contain no
attacks, and `evil` events appear only in the test split (1 host). Confirm this with `python -m triage describe`
once you have the files, because the benchmark protocol depends on it.

Download with the Kaggle CLI:

1. Create a Kaggle account, then Account settings > API > Create New Token (saves `kaggle.json`).
2. Put it at `~/.kaggle/kaggle.json` (never inside this repo).
3. Run `bash scripts/download_beth.sh`.

Expected files in `data/beth/`: `labelled_train.csv`, `labelled_validation.csv`, `labelled_test.csv`.
If the names differ, rename them or edit `SPLITS` in `src/triage/cli.py`.

Columns used: `timestamp, processId, parentProcessId, userId, processName, hostName, eventName, returnValue, args`
(plus `sus` and `evil` for benchmarking only). `args` is a Python-style list of dicts such as
`[{'name': 'pathname', 'type': 'const char*', 'value': '/etc/passwd'}]`.

## Synthetic sample (in the repo)

`data/sample/` is generated by `scripts/make_sample_data.py`. It is BETH-shaped and fake: it exists so
tests, CI and the dashboard demo work before anyone downloads BETH. In it `sus` equals `evil`, which is
not true of the real data, so baseline comparisons on the sample mean nothing.
